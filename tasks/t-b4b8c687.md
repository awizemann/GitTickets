## Description

Reported by Alan from ScarfRack (2026-10-05, screenshot): in a macOS sheet, My Reports shows Refresh on the left of the bottom bar and "Done" + a blue prominent compose button on the right. The compose ("Report an issue", onNew) button sits where a confirm button goes and looks like the default action, which is confusing next to Done. Cause is ours: GitTicketsMyIssuesView puts onNew in ToolbarItem(placement: .primaryAction) (GitTicketsMyIssuesView.swift ~210); in a macOS sheet .primaryAction renders as the trailing default-styled button. Refresh is .automatic (RefreshTriggers.swift ~111). Goal: on macOS the new-report button sits with Refresh, Done alone on the right; iOS layout unchanged unless also wrong.

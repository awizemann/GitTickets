## Description

GitTicketsMyIssuesView has no close control when shown in a sheet; ScarfRack added its own Done bar. Add an optional `onClose: (() -> Void)? = nil` to the public inits; when set, show a "Done" toolbar button (confirmation/cancellation placement) that calls it. Explicit closure rather than @Environment(\.dismiss): in a Window scene dismiss would close the whole window unexpectedly. Additive, source-compatible.

## Plan

1. Add onClose to every public init (default nil), thread through.
2. Toolbar Done button only when non-nil; keyboard Escape/⌘. via cancelAction placement where appropriate.
3. Tests: init compiles with/without; closure fires; no button when nil.
4. swift build + swift test green.

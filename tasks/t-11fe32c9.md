## Description

Reply-alert audit (2026-10-05): /my-issues and /comments draw from the same per-device (10/h) and per-IP (30/h) buckets as /report, so reading replies — checkForReplies, My Reports refreshes, 5xx retries — can 429 the user's next bug report. Give read endpoints their own buckets (separate keys + limits, defaults generous enough for normal use) so reads can never block filing. Both relays, wire contract unchanged, docs/vars updated. Older deployed relays keep working (client-side throttle still applies).

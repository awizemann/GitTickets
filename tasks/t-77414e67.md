## Description

Alan's ruling (2026-10-05): adopter-specific relay configs never live in the GitTickets repo (it is public). Document the pattern generically in relay/cloudflare/README.md: keep your own wrangler.toml in your app's repo, fetch the GitTickets relay at a pinned SDK tag into a temp dir, copy config in, npm ci, wrangler deploy; secrets per Worker via `wrangler secret put --name`. No ScarfRack specifics. ScarfRack's own handoff: documents/handoffs/2026-10-05-scarfrack-relay-config-handoff.md.

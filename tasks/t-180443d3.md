## Description

latestComment in relay/cloudflare/src/lib/github.ts:170 and relay/vercel/api/_lib/github.ts:187 calls GET /repos/:o/:r/issues/:n/comments?per_page=1&sort=created&direction=desc. That endpoint only accepts since/per_page/page, so it returns the OLDEST comment. latestReplyAt drives "last reply X ago" (IssueDetailView.swift:178) and My Reports sort order (GitTicketsMyIssuesView.swift:195). Fix: per_page=1&page=<issue.comments> (count already known at handlers/myIssues.ts:92). Both relays + tests. Found 2026-10-05 in the reply-alert design. Candidate for 2.6.0 since ScarfRack deploys the relay at the SDK tag.

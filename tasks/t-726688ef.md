## Description

From the read-bucket audit (2026-10-05): every /my-issues call lists up to 5 pages of labelled issues on the shared GitHub App installation token, which /report also needs. The list is identical for every caller, so a 30–60s per-isolate/instance cache would remove most of that traffic. Also consider bucketing IPv6 by /64 (one /64 gives effectively unlimited per-IP buckets today) and capping submissionIDs per request.
